# Signet

A hold-to-confirm button for React, adapted to mobile and desktop. For actions
worth a moment of deliberation — deleting, paying, deploying — where a plain
click is too easy and a type-the-name dialog is too much.

- **Hold** — press and hold to confirm.
- **Undo** — tap once to confirm, tap again within a few seconds to undo.
- **Auto** — switches between hold and undo based on the device's pointer type.

```bash
pnpm install
pnpm dev
```
